Quick Start

Step 1: Access Pico-8

  1. Go to https://www.pico-8-edu.com/
  2. Press the Play button
  3. You should now see the Pico-8 interface

Step 2: Running Code

  1. You can switch between the console and IDE by pressing ESC
  2. To load a file, type: LOAD FILENAME.P8 (replace FILENAME with the file name)
  3. To run the code, type: RUN
  4. To end a program, press ESC again to return to the console
  5. To edit code, press: ESC

Step 3: Try Your First Program

Type this directly into the console and press Enter:

print("Hello world!")
What this does
  • print() → Tells Pico-8 to display text on the screen
  • "Hello world!" → The text to display (must be in quotes)
  • Enter → Runs the command you typed

Step 4: Make it Interactive

Try this next one in the console:

x = 64
y = 64
print("Your character is at", x, y)
Explanation
  • x = 64 → Creates a variable x and sets it to 64
  • y = 64 → Creates a variable y and sets it to 64
  • print("Your character is at", x, y) → Shows text plus the current values of x and y

Step 5: Next Steps

Once you can see your first printed text and variables:

  • Press ESC to open the code editor
  • Type `_update()` and `_draw()` stubs (you'll learn these in the first club meeting)
  • Run small changes and see what happens
  • Experiment with changing numbers and text
