Quick Start

Minimal PICO-8 Program


x = 64
y = 64

function _update()
  if btn(0) then x -= 1 end
  if btn(1) then x += 1 end
  if btn(2) then y -= 1 end
  if btn(3) then y += 1 end
end

function _draw()
  cls()
  rectfill(x, y, x+8, y+8, 7)
end

How to run it

Paste this into PICO-8. Press Run. Move the box.

How it works (human version)

_update() is where the game thinks.

_draw() is where the game shows.
