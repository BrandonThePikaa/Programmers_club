Welcome to the PICO-8 Game Club

What we do

We make small games. We learn how games work. We break things and fix them. No prior programming experience required.

What is PICO-8?

PICO-8 is a fantasy console used to make small retro-style games. It uses a simple version of Lua and forces creativity through limitations.

No experience needed

Seriously. If you can read and type, you can do this.
